How the sheet connection works

The dashboard can't open your Google Sheet by itself. So you add a small script to the sheet, and Google gives that script a web address, the web app URL. The dashboard sends new and changed brands to that address, and the script writes them into the sheet. It works the other way too: the dashboard asks the address for the latest rows, and the script reads them out of the sheet.

The script edits the sheet as the person who set it up, so teammates don't need edit access to the sheet itself. Anyone who has the address could send it data, so it only accepts requests that include the team token, a password you choose. Keep both within the finance team.

One-time setup

Link a sheet in five steps

  1. Create a Google Sheet for the team, then open Extensions → Apps Script.
  2. Replace Code.gs with the script below and change TOKEN to a long random phrase.
  3. Deploy → New deployment → Web app. Execute as Me, access Anyone. Authorise it.
  4. Copy the Web app URL and paste it, with the token, into the form on the left.
  5. Share the URL and token with the finance team only. The sheet gets Brands and Drafts tabs.
